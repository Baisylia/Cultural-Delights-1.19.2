### Added

- Cultural Delights now bundles all features from Cook's Collection directly (because of this, Cook's Collection is no
  longer a required dependency).
- Harvesting mature corn with a knife now drops straw.
- Ported decorative Brick Counters (including Ash Brick Counters for Supplementaries and Silt Brick Counters for Twigs)
  from Raspberry Core that connect to adjacent counters.
- Ported Marshmallow and Marshmallow on a Stick from Raspberry Core, which can be cooked over Campfires and heat
  sources.
- Added EMI and JEI integration for marshmallow cooking recipes.
- Added an optional Stove retexture ported from Raspberry Flavoured that updates Farmer's Delight stove textures to
  closer match the brick counters.

### Changed

- Improved mod compatibility with more tags in recipes.

### Fixed

- Fixed suspended bean model being shaded.
